# smart_form_fields example

A Material 3 application with three focused demonstrations:

1. **Registration form** — reusable fields, sync/async validation, validation
   timing, first-error navigation, submission, reset, and a custom boolean
   field.
2. **JSON API form** — a snake_case API schema, named async validators, custom
   validator builders, and a custom JSON field builder.
3. **Controller playground** — key/controller access, values, `setValue`,
   `patchValue`, reset, server errors, focus/scroll commands, disabled and
   dynamic fields, and a custom bottom-sheet selection field.

`SmartFormTheme` supplies shared behavior defaults at the application level.

Run it from this directory:

```sh
flutter run
```
